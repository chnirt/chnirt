# Cover letter — how to tailor

Harvard MCS tips (not included in the PDF):

1. Address a real person when possible (`Dear Alex Nguyen:`), not “To Whom It May Concern.”
2. Replace the bracketed company sentence with one specific fact from their product, blog, or job post.
3. Keep to one page; keep examples factual and quantified.
4. Mirror 2–3 keywords from the job description (e.g. React Native, NestJS, GraphQL, CI/CD).
5. Match font/style with the resume PDF when attaching both.
6. Customize `[Company]`, `[Hiring Manager]`, `[Role]` in `COVER_LETTER.md` before running `npm run pdf`.
